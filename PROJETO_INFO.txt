🚀 COMO INICIAR

1. Abra um terminal na pasta do projeto:
   cd "e:\Catálogo Perfumes\catalogo-perfumes"

2. Inicie o servidor de desenvolvimento:
   npm run dev

3. Acesse no navegador:
   http://localhost:3000

4. Popular banco de dados com dados de exemplo:
   http://localhost:3000/api/init

5. Acessar painel admin:
   http://localhost:3000/admin

📊 BANCO DE DADOS

SQLite com 2 tabelas:

CATEGORIES:
  - id (INTEGER PRIMARY KEY)
  - name (TEXT UNIQUE)

PRODUCTS:
  - id (INTEGER PRIMARY KEY)
  - name, brand, price, volume_ml
  - description, short_description
  - olfactory_notes
  - category_id (FK)
  - image_url
  - created_at, updated_at

Dados de Exemplo Incluídos:
  1. Bleu de Chanel (100ml, R$450)
  2. Coco Mademoiselle (100ml, R$480)

  4. Sacentum (100ml, R$89,90)
  5. Arabian Oud Premium (100ml, R$650)

❓ DÚVIDAS FREQUENTES

P: Como adicionar mais perfumes?
R: Acesse http://localhost:3000/admin e use o formulário

P: Como resetar o banco de dados?
R: Delete a pasta data/perfumes.db e visite /api/init novamente

P: Como mudar as cores?
R: Edite as classes Tailwind nos componentes (procure por "amber-900")

P: Como adicionar imagens?
R: Na página de admin, forneça URLs válidas de imagens

P: Como customizar o WhatsApp?
R: Edite .env.local com seu número
